Vnano Text プラグイン群
(org.vcssl.nano.plugin.text パッケージ)

概要

このパッケージ/サブパッケージ内のプラグイン群は、Vnano (VCSSL nano) のスクリプトから利用できる、文字列処理関数などを提供します。
なお、このプラグイン群の提供機能は、VCSSL の標準ライブラリである VCSSL Text ライブラリ の機能のサブセット（※）になっています。 そのため、VCSSL のスクリプトにおいても、ほぼ同様の機能が標準で利用可能です。 ただし、その際は VCSSL スクリプトの先頭で「 import Text; 」と記述し、ライブラリを読み込む必要があります。

TextBasicXnci1Plugin
(org.vcssl.nano.text.xnci1.TextBasicXnci1Plugin)

基礎的な文字列処理機能を提供するプラグインです。

変数

変数 ALL
値 文字列と一致する、全ての部分を探す検索モードです。
データ型 int (定数)
変数 ALL_PATTERN
値 正規表現と一致する、全ての部分を探す検索モードです。
データ型 int (定数)
変数 FIRST
値 文字列と一致する、最初の部分を探す検索モードです。
データ型 int (定数)
変数 FIRST_PATTERN
値 正規表現と一致する、最初の部分を探す検索モードです。
データ型 int (定数)
変数 LAST
値 文字列と一致する、最後の部分を探す検索モードです。
データ型 int (定数)
変数 LAST_PATTERN
値 正規表現と一致する、最後の部分を探す検索モードです。
データ型 int (定数)

関数

関数 atText( text, index )
機能 文字列内の、指定された位置にある文字を取得します。
宣言形式 string atText( const string text, const int index )
引数 (string型) text: 取得したい文字を含む文字列。
(int型) index: 取得したい文字の位置インデックス（最初の文字が 0 ）。
戻り値 (string型) 取得した文字
使用例 string s = atText("ABCDE", 3); // "D"
