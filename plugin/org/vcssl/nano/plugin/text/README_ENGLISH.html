Vnano Text Plug-in Group
(org.vcssl.nano.plugin.text package)

Abstract

Plug-ins in this package/subpackages provide string (text) process functions available in scripts of the Vnano (VCSSL nano).
Features provided by these plug-ins is a subset of the VCSSL Text Library which is a standard library of the VCSSL, so same features are also available in scripts of the VCSSL by default, with importing them at the head of the script as: " import Text; "

List of Provided Plug-ins and Features

Functions

Function atText( text, index )
Feature Gets the character at the specified index in the text.
Signature string atText( const string text, const int index )
Params (string) text: The text from which the character will be picked up.
(int) index: The character index in the text (the index of the first character is 0).
Return (string) The character at the specified index.
Example string s = atText("ABCDE", 3); // "D"
Function adjustText( text, mode )
Feature Adjusts the text in the specified mode.
Depending on the mode, it trims spaces at the head/tail in the text, or converts alphabets in the text to upper/lower case characters.
Signature string adjustText( const string text, const int mode )
Params (string) text: The text to be adjusted.
(int) mode: The adjustment mode（ TRIM, LOWER_CASE, UPPER_CASE ）
Return (string) The adjusted text.
Example string s = atText(" ABCDE ", TRIM); // "ABCDE"
string s = atText("ABCDE", LOWER_CASE); // "abcde"
string s = atText("abcde", UPPER_CASE); // "ABCDE"
Function cropText( text, cropBegin, cropEnd )
Feature Crops a partial string from the text.
Specify the cropping range by indices assigned to "boundaries between characters." The index 0 points the beginning point (generarry left-edge) of the text. This function crops the partial string between cropBegin-th boundary and cropEnd-th boundary.
In other words, if you want to regard these indices as "indices assigned to characters", this function crops the partial text from cropBegin-th character to (cropEnd-1)-th character.
Signature string cropText( const string text, const int cropBegin, const int cropEnd )
Params (string) text: The text from which the partial string to be cropped.
(int) cropBegin: The index of the beginning point of the partial text to be cropped.
(int) cropEnd: The index of the end point of the partial text to be cropped. See the description in "Feature" section.
Return (string) The cropped text.
Example string s = cropText("ABCDE", 1, 3); // "BC"
